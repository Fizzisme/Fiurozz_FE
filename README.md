# Fiurozz

> A modern portfolio and project showcase platform for software engineers.

Fiurozz is a full-stack web platform designed to present software engineering projects in a clean, elegant, and interactive way. Instead of being just another portfolio website, Fiurozz focuses on storytelling—highlighting project architecture, technical decisions, development process, and engineering experience.

The platform is built with scalability and maintainability in mind, following a modern microservices architecture and contemporary UI/UX principles.

---

##  Features

-  Modern and minimal UI inspired by Vercel and shadcn/ui
-  Project showcase with detailed technical documentation
-  Technical blog system
-  Personal portfolio
-  Advanced project search
-  Fully responsive design
-  Dark mode support
-  Optimized for SEO
-  High performance with Next.js App Router

---

##  Tech Stack

### Frontend

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- shadcn/ui

### Backend

- Go (API Gateway)
- NestJS Microservices
- RabbitMQ
- Prisma ORM
- PostgreSQL
- Redis

### Infrastructure

- Docker
- Docker Compose
- Nginx
- GitHub Actions

##  Getting Started

Clone the repository.

```bash
git clone https://github.com/your-username/fiurozz.git
```

Install dependencies.

```bash
npm install
```

Start the development server.

```bash
npm run dev
```

Open your browser.

```
http://localhost:3000
```
